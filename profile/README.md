# Conventional Context

This organization `conventional-context` is a **namespace reservation**. It holds no projects.

Conventional Context lives at **[github.com/conventionalcontext](https://github.com/conventionalcontext)**.

- Specification, templates, and tooling: [conventionalcontext/conventionalcontext](https://github.com/conventionalcontext/conventionalcontext)
- Website: [conventionalcontext.org](https://conventionalcontext.org)

Please open issues, discussions, and pull requests there. Anything filed
here will not be seen.

This org is maintained by the Conventional Context maintainers to prevent
confusion with the dashed spelling of the name.
